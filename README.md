# Video Compressor

A simple command-line video compression tool written in Python.

It uses Click for the command-line interface and FFmpeg for video encoding.

## Requirements

- Python 3.12+
- FFmpeg

## Installation

Clone the repository and create a virtual environment:

```bash
python -m venv .venv
source .venv/bin/activate
```

Install the project:

`pip install -e .`

Usage

`videocomp compress input.mp4`
